## 反方挑战

- 事实证据在哪里：每个品牌/电话/服务/媒体/边界均回指 FACT REGISTER 或 MEDIA MANIFEST。
- 是否扩大地域：只说 Sydney enquiry，不列未经确认 suburb。
- 是否扩大结果：项目图不声明客户、地点、日期、修复结果或保修。
- 是否稀释 Owner：Home 保留 Generic Core Query；细分页只回答具体症状/材料/构件。
- SSR 是否可验证：需在本地 HTTP 验收中逐路由确认初始 HTML、状态码、robots header 与语言属性。
